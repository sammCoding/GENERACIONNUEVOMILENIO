# UEGNM — Generación Nuevo Milenio

Landing Page estática para el proyecto escolar “Mi Colegio, Mi Marca”.

## Estructura
- `index.html`
- `style.css`
- `script.js`
- `assets/video.mp4` (colocar aquí el video promocional)
- `assets/` (colocar aquí fotografías reales cuando estén disponibles)

## Fotografías
Los bloques de galería son placeholders intencionales. Para usar imágenes reales,
se pueden sustituir por `<img src="assets/nombre.jpg" alt="Descripción">`.

## Video
Coloca el archivo vertical 9:16 en:
`assets/video.mp4`

No se agregaron datos institucionales que no fueran proporcionados.
